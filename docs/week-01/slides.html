What is data? 😶‍🌫️
Got a question for you:
"when I think about data, I'm thinking of...?"
When I think about data, I'm thinking of...
- that thing I pay for as part of my monthly phone contract 😶‍🌫️
When I think about data, I'm thinking of...
- a spreadsheet of rows and columns, displayed within the green-ish Excel interface 🧩
When I think about data, I'm thinking of...
- information about me and my user behaviour on Facebook, Instagram, ChatGPT... 😎
When I think about data, I'm thinking of...
- the recorded observation that scientists made from physics experiments, e.g. the large hadron collider in CERN

These are all data!

In fact, they represent different perspectives about data:

- data in phone📱: digital, quantized for easy measurement (e.g. 250GB)

- data in a spreadsheet📋: structured, note that not all data can be put into rows and columns

- data about me on social media🧃: behavioural data, include more than just numbers (e.g. the images I have uploaded)

- data from scientific experiments🔬: natural data, comes from observation

- - - and I'm still gaining new understanding about data...

Representation can be contextual.
Depends on the problem context, different tasks may have different efficient representations for the same objects.
Takeaway messages on representation:
- It can be descriptive and capture some characteristics.
- It can be perspective and partial.
- It can be contextual where "good" ones are task-dependent.
